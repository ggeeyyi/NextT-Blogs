The Research Trace: behind AttnRes-Canon

This page replays the session in which Claude Opus 5.5 found AttnRes-Canon, the story told in the post. One time axis carries what the operator approved, when the agent worked, each experiment from launch to result, the reviews it asked for and its one web search. Pick any turn to read its input, what the agent did and what it answered. Times are UTC+8.

How to read it

  • A turn starts when the operator sends an input, or when a background watcher that the agent set earlier finishes (for example “wait until any run ends”). Four turns, drawn as outlined bars, start after the operator resumed a stalled session without a new instruction. Between turns the agent is idle.
  • An experiment is a thin line while it waits for GPUs and a bar while it trains. “Result back” marks the first turn shown here after the run finished.
  • The operator's inputs are shown in English. The opening brief is translated in full; the later ones are summarized as what was approved, with the compute budget where one was set. An approval is a circle with a check.
  • Exchanges off the main line of the research are left out: status checks, side questions, housekeeping and work unrelated to the research.
  • The agent's replies and notes are in English. Replies marked “translated” are translations, as are some of the notes.
  • The agent's one web search has an entry of its own in the list of turns, with the query and everything the search returned.
  • Names of the compute cluster, file paths and job names are replaced with neutral words, and passages about the cluster's state and interfaces or about publishing logistics are removed, so some replies are shorter than the agent wrote them.
