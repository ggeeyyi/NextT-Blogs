# How Opus Found AttnRes-Canon

A standalone, dependency-free post about how Claude Opus found AttnRes-Canon in NextTransformer Arena v1, in two
synchronized versions:

- `index.html`: English, the default page, *How Opus Found AttnRes-Canon: The Discovery Trace of an Architecture Search*;
- `zh/index.html`: Simplified Chinese, *Opus 如何找到 AttnRes-Canon：一次架构探索的 Discovery Trace*;
- `en/index.html`: a redirect to the post, so that links to the English version's earlier address keep working.

## Files

- The two `index.html` files hold the text and the hand-typed tables; `styles.css` is shared. The page wears the look
  of the NextTransformer observatory: its paper, accents, top bar and title card.
- `assets/` holds what the page borrows from the project: the IAAI logo, the observatory illustration, the project
  logo and the Kalam fonts of the wordmark (SIL Open Font License, `assets/fonts/Kalam-OFL.txt`).
- `figures.js` draws the twelve figures as inline SVG in the language of `<html lang>`, at the pixel width of their
  container. Each animates once when it scrolls into view and ends in the complete figure; with reduced motion or in
  print the complete figures are drawn at once.
- `site.js` handles the theme toggle, reading progress, the section rail and entrance motion. The article reads in
  full without it.
- `data.js` is generated by `scripts/build_data.py` and holds only what the figures draw.

## Data and checks

Every number in the figures, tables and prose comes from the Arena v1 evidence (`evidence/checks/arena-v1-stage*`)
and the published run records (`results/runs/`) of a NextTransformer checkout. Point the scripts at that checkout:

```bash
export NEXTTRANSFORMER_REPO=/path/to/NextTransformer
python3 attnres-canon/scripts/build_data.py     # rewrites data.js
python3 attnres-canon/scripts/check_numbers.py  # recomputes every table and quoted number
```

`check_numbers.py` fails if a table cell, a bold mark or a number in the prose of either page disagrees with the
evidence, or if `data.js` is stale. The published results are read at a git ref of that checkout (`--published-ref`,
default `origin/main`).
